<h1 align="center">🗺️ Dimension TAB</h1>

<p align="center"><strong>See where every player is — at a glance.</strong></p>

<br>

---

<br>

<h2>✨ Overview</h2>

<p>Dimension TAB shows the current dimension of each player in the tab list. No more asking "where is everyone?" — just open the player list and see instantly. Fully configurable via in-game commands, no config files to edit.</p>

<br>

<h2>🎯 Features</h2>

<h3>🎨 Per-Dimension Colors</h3>
<p>Each dimension gets its own color: green for Overworld, red for Nether, purple for the End. Set custom colors for any modded dimension using Minecraft color names or hex codes.</p>

<h3>📝 Customizable Format</h3>
<p>Use tokens to build your own display: <code>%dim:name%</code>, <code>%dim:id%</code>, <code>%dim:namespace%</code>, <code>%dim:path%</code>. Default format: <strong>[%dim:name%]</strong>.</p>

<h3>🏷️ Dimension Aliases</h3>
<p>Give dimensions friendly names. Show "The Aether" instead of "aether:the_aether", or "The End" instead of "minecraft:the_end".</p>

<h3>📐 Flexible Placement</h3>
<p>Choose whether the dimension tag appears before (prepend) or after (append) the player name.</p>

<h3>🖥️ Server-Side Only</h3>
<p>Runs entirely on the server. Players don't need to install anything. If installed on the client, it provides an in-game config screen via the Mods menu.</p>

<h3>⚙️ In-Game Commands</h3>
<p>Full runtime configuration via <code>/dimensiontab</code> — change colors, aliases, format, and more without restarting.</p>

<h2>🎮 Commands</h2>

<ul>
<li><code>/dimensiontab color &lt;dimension&gt; &lt;color&gt;</code> — Set dimension color</li>
<li><code>/dimensiontab alias &lt;dimension&gt; &lt;alias&gt;</code> — Set custom name</li>
<li><code>/dimensiontab format &lt;format&gt;</code> — Change display format</li>
<li><code>/dimensiontab placement prepend|append</code> — Tag position</li>
<li><code>/dimensiontab refresh</code> — Refresh all player names</li>
<li><code>/dimensiontab reload</code> — Reload config</li>
<li><code>/dimensiontab dimid</code> — Show your dimension ID</li>
<li><code>/dimensiontab list colors|aliases</code> — List custom settings</li>
</ul>
