<h1 align="center">💬 Info TAB</h1>

<p align="center"><strong>Player info at a glance — dimension, AFK, and more in the tab list.</strong></p>

<br>

<hr>

<br>

<h2>✨ Overview</h2>

<p>Info TAB shows each player's current dimension and AFK status in the tab list. See who's away, where everyone is, and never ask "where is everyone?" again. Fully configurable via in-game commands.</p>

<br>

<h2>🎯 Features</h2>

<h3>🛌 AFK Detection</h3>
<p>Players inactive for 10+ minutes get an <code>[AFK]</code> prefix in creme color. Activity is tracked via movement, interactions, chat, and combat.</p>

<h3>🎨 Per-Dimension Colors</h3>
<p>Each dimension gets its own color: green for Overworld, red for Nether, purple for the End. Set custom colors for any modded dimension using Minecraft color names or hex codes.</p>

<h3>📝 Customizable Format</h3>
<p>Use tokens to build your own display: <code>%dim:name%</code>, <code>%dim:id%</code>, <code>%dim:namespace%</code>, <code>%dim:path%</code>. Default format: <strong>PlayerName [%dim:name%]</strong>.</p>

<h3>🏷️ Dimension Aliases</h3>
<p>Give dimensions friendly names. Show "The Aether" instead of "aether:the_aether".</p>

<h3>📐 Flexible Placement</h3>
<p>Choose whether the dimension tag appears before (prepend) or after (append) the player name.</p>

<h3>🖥️ Server-Side Only</h3>
<p>Runs entirely on the server. Players don't need to install anything.</p>

<h3>⚙️ In-Game Commands</h3>
<p>Full runtime configuration via <code>/infotab</code> — change colors, aliases, format, and more without restarting.</p>

<br>

<h2>🎮 Commands</h2>

<ul>
<li><code>/infotab color &lt;dimension&gt; &lt;color&gt;</code> — Set dimension color</li>
<li><code>/infotab alias &lt;dimension&gt; &lt;alias&gt;</code> — Set custom name</li>
<li><code>/infotab format &lt;format&gt;</code> — Change display format</li>
<li><code>/infotab placement prepend|append</code> — Tag position</li>
<li><code>/infotab refresh</code> — Refresh all player names</li>
<li><code>/infotab reload</code> — Reload config</li>
<li><code>/infotab dimid</code> — Show your dimension ID</li>
<li><code>/infotab list colors|aliases</code> — List custom settings</li>
</ul>
