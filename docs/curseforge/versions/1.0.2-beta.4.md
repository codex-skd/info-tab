<h2>v1.0.2-beta.4 - Configurable AFK and dimension display</h2>

<h3>Added</h3>
<ul>
<li><strong>Config options</strong>: Two new settings in the config file and <code>/infotab setting</code> command:
  <ul>
  <li><code>showAfk</code> (default: <code>true</code>) — Show/hide the <code>[AFK]</code> prefix.</li>
  <li><code>showDimension</code> (default: <code>true</code>) — Show/hide the dimension tag.</li>
  </ul>
</li>
</ul>
