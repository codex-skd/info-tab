<h2>v1.0.2-beta.5 - Configurable AFK timeout and tick-based movement tracking</h2>

<h3>Added</h3>
<ul>
<li><strong>Config option</strong>: <code>afkTimeoutMinutes</code> (default: <code>10</code>, range: 1-9999) — define how many minutes of inactivity before showing <code>[AFK]</code>.</li>
</ul>

<h3>Fixed</h3>
<ul>
<li><strong>AFK detection reliability</strong>: Movement is now checked every 5 seconds via <code>ServerTickEvent</code>, independent of tab list refreshes.</li>
</ul>
