<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Info TAB for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). API port of the stable 26.2 line (1.1.0) &mdash; same feature set.</p>

<h3>About this build</h3>
<ul>
<li><strong>API port</strong> of the 26.2 source (14 classes, no dependencies, no mixins) to the 1.21.1 API: <code>net.minecraft.resources.Identifier</code> &rarr; <code>ResourceLocation</code>; <code>ResourceKey&lt;Level&gt;.identifier()</code> &rarr; <code>.location()</code>; <code>RenderNameTagEvent.CanRender</code> &rarr; the single <code>RenderNameTagEvent</code>; <code>ClientPacketDistributor</code> &rarr; <code>PacketDistributor</code>; <code>Minecraft.gui.screen()</code> &rarr; <code>Minecraft.screen</code>.</li>
<li><strong>Feature set</strong>: dimension in the tab list, per-dimension colours, token format, aliases, prepend/append placement, <code>[AFK]</code> tag in the tab list and above the head, the <code>/infotab</code> command and the config screen.</li>
</ul>

<h3>Notes</h3>
<blockquote>Tab-list / name-tag info mod, no gameplay content. Verified: <code>./gradlew build</code> and <code>./gradlew runServer</code> load cleanly &mdash; <code>Done (6.3s)</code>, 0 FATAL. Client-side rendering (name tag, tab list) compiles but is not yet verified in-game.</blockquote>
