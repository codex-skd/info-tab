<h2>v1.0.5 - AFK resets on mouse/keyboard input</h2>

<h3>Added</h3>
<ul>
<li><strong>AFK now resets on input, not just movement</strong>: looking around, clicking, or pressing keys while playing (no menu/inventory open) resets the AFK timer, in addition to the existing movement and world-interaction triggers.</li>
</ul>

<h3>Removed</h3>
<ul>
<li>Debug logs used during AFK development have been removed now that the feature is stable.</li>
</ul>
