<h2>v1.0.2-beta.1 - AFK Detection & Rebrand to Info TAB</h2>

<h3>Added</h3>
<ul>
<li><strong>AFK Detection</strong>: Players inactive for 10+ minutes now show a <code>[AFK]</code> prefix in creme color (<code>#FFFDD0</code>).</li>
</ul>

<h3>Changed</h3>
<ul>
<li><strong>Rebrand</strong>: Mod renamed from Dimension TAB to <strong>Info TAB</strong>.</li>
<li><strong>Display format</strong>: <code>[AFK] PlayerName [%dim:name%]</code> — AFK prefix before name, dimension suffix after.</li>
<li><strong>Command</strong>: <code>/dimensiontab</code> renamed to <code>/infotab</code>.</li>
</ul>
